# Session, 2026-10-02: release 1.0.53, website re-captured, Pages clash

Release **1.0.53** (PR #99): playlists, hot cues, Compare with Rekordbox, Energy/LUFS/Volume Score,
the website.

## Website captures on a Mac
- `site:capture` skipped clips off Linux; with no Linux at hand it now records them with
  Playwright's video of the page ([ADR 0056](../adr/0056-website-clips-recorded-on-a-mac-too.md)).
- Gotchas found: a Mac app ignores `XDG_CONFIG_HOME`, so the first probe launch opened the **dev**
  data folder (`~/Library/Application Support/music-collection-organizer`) — now
  `--user-data-dir`. The 1600×1000 window doesn't fit a laptop screen: `setViewportSize` sizes the
  page instead. The executable path was Linux-only (`node_modules/electron/dist/electron`).

## Bug: the website's deploy wiped the Cast receiver
- On merging #99, the new Website workflow and *Deploy Cast receiver* shared the `pages`
  concurrency group (cancel-in-progress). The receiver run was cancelled, the website deployed
  alone, and a Pages deploy replaces the whole site: `/cast-receiver/` returned 404, so casting
  failed for every installed MCO.
- Fix: one Pages workflow that deploys both
  ([ADR 0057](../adr/0057-one-pages-deploy-for-website-and-receiver.md)).

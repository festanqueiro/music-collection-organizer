# Session, 2026-09-30 → 10-01: Show on a screen fixes, Stats, visualisers 0.3.0

Release **1.0.52**.

## Bugs found (both in Show on a screen, since 1.0.50/1.0.51)
- **Now playing showed only a huge logo.** The child window (`window.open('')`) inherits the main
  page's Content-Security-Policy (`default-src 'self'`, no `'unsafe-inline'`), so the `<style>`
  holding `nowPlaying.css` was blocked: the 1024 px icon rendered at full size and the text was dark
  on black. Fix: a constructed `CSSStyleSheet` in `adoptedStyleSheets` (not subject to CSP).
  Anything else injected into the child must avoid inline `<style>` too.
- **Visualizers stayed black (white in a window), track info fine.** The render loop passed the
  child's `requestAnimationFrame` timestamp to `VisualizerEngine.render()`. The child's clock starts
  when it opens, the engine's `lastMs` is on the main page's clock, so the first frame's `dt` was
  hugely negative and the smoothing went to Infinity/NaN for good. Fix: time frames with the main
  page's `performance.now()`, as the Mac's visualizer does.
- A plain WebGL canvas created in the main document and moved into the child draws fine — ruled out
  first.

## Shipped
- **Stats** ([feature](../features/stats.md)); **Add to queue** icon per row; visualizer controls
  moved to the bottom (they covered long titles) and the frame-rate pill shows "30 fps" again; BPM
  removed from the second screen's track info.
- **threejs-visualisers 0.3.0**: Origins theme, Liquid 3D → Liquid (same id). The store's list of
  valid theme ids was hand-written and missed Origins (a saved pick would reset to Nebula); it's now
  a `Record<VisualizerThemeId, true>` so tsc catches a new theme.

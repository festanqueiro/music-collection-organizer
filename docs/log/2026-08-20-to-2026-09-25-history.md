# History, 2026-08-20 → 2026-09-25

A summary reconstructed from git history and the design documents in this folder, so the early
decisions have a home. Details are in the linked ADRs and the dated design docs.

## 2026-08-20 — v1: the library organizer
- [Design](2026-08-20-v1-library-organizer-design.md) and [plan](2026-08-20-v1-library-organizer-plan.md):
  an Electron app that scans one folder (Google Drive for Desktop), analyses tracks and lets the user
  tag and filter them ([ADR 0002](../adr/0002-electron-react-typescript.md)).
- `better-sqlite3` couldn't be built for Electron on the dev machine; replaced by `node:sqlite`
  ([ADR 0003](../adr/0003-node-sqlite.md)).
- Scans flag missing files instead of deleting rows, so tags survive ([ADR 0004](../adr/0004-never-delete-track-rows.md)).
- Cloud-only detection from allocated blocks ([ADR 0005](../adr/0005-cloud-only-detection.md));
  analysis in worker threads ([ADR 0006](../adr/0006-analysis-in-worker-threads.md)).

## 2026-08-21 → 2026-08-22 — player, FX, backups
- [Progress indicator + settings/backups](2026-08-21-progress-indicator-and-settings-backup-design.md),
  [collection & backup features](2026-08-21-collection-and-backup-features-design.md) (batch tagging,
  tag export/import, restore, undo), [playlist/queue](2026-08-21-playlist-feature-design.md)
  ([ADR 0012](../adr/0012-fifo-queue.md)), [Dub Siren](2026-08-21-dub-siren-fx-design.md).
- Daily `VACUUM INTO` backups ([ADR 0011](../adr/0011-daily-database-backups.md)); AIFF via cached FLAC
  ([ADR 0010](../adr/0010-aiff-playback-via-flac-cache.md)); the data folder moves inside the
  collection ([ADR 0009](../adr/0009-data-folder-inside-collection.md)).
- MIDI never connected until `requestMIDIAccess` was bound to `navigator` and `midiSysex` granted; FX
  sends became post-fader so muting mutes.

## 2026-08-23 → 2026-09-01 — polish
- Tag colours, LP/HP knobs, subtags view, EQ ±24 dB, output device selection, Settings tabs, track
  table multi-drag / resizable and sticky columns / shift-select, MIDI fixes (knob lag, duplicate
  bindings, Note/CC matching).

## 2026-09-22 → 2026-09-24 — first public release (1.0.28)
- Media keys / AirPods controls, AND/OR tag filter, visualizer (4 themes), queue actions, MIDI
  settings, the Sound System model.
- Release workflow with ad-hoc signing, the custom updater ([ADR 0013](../adr/0013-github-releases-updater-ad-hoc-signing.md)),
  harmonic mixing, pre-listen, Rekordbox export, watch folder, MP3/AAC/OGG. A duplicate finder was
  added, then removed in PR #51.

## 2026-09-25 → 2026-09-26 (early) — loader and casting
- Casting first streamed MCO's live output ([ADR 0015](../adr/0015-cast-by-streaming-live-output.md)),
  then moved to direct playback ([ADR 0016](../adr/0016-cast-direct-mode.md)) and MCO's own receiver
  app ([ADR 0017](../adr/0017-own-cast-receiver-app.md)); visualizers moved to their own package
  ([ADR 0014](../adr/0014-visualizers-in-their-own-package.md)); AirPlay dropped
  ([ADR 0019](../adr/0019-no-airplay.md)); themes, Settings rework, Queue/FX screens (1.0.35–1.0.37).

The rest of 2026-09-26 is in the [session write-up](2026-09-26-session.md).
